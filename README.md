# Smart Sales CRM Pro v2.0 (Enterprise Edition)

تطبيق سطح مكتب متكامل مبني بـ **Python + CustomTkinter + SQLite (WAL) + Playwright** لسحب العملاء وإدارتهم عبر مراحل المبيعات، مع إرسال يدوي آمن (0% خطر حظر) وحملات متعددة القنوات محمية بدرع تجنب البان.

## أبرز التطويرات في الإصدار v2.0
1. **إصلاح مشاكل السحب والـ Live Log:**
   - تسجيل فوري لكل رابط يتم فتحه، كل عميل يتم استخراجه، سبب القبول أو الاستبعاد، وأي خطأ يحدث بدون ابتلاع صامت للأخطاء.
   - تجاوز تلقائي لنوافذ موافقة Google Maps واستخراج مرن لصفحات LinkedIn حتى مع تغير الـ CSS Classes.
   - فحص موقع كل شركة (الصفحة الرئيسية + صفحة Contact) لاستخراج الإيميل ورقم الواتساب.
2. **السحب والإرسال في نفس الوقت (True Concurrency):**
   - قاعدة بيانات SQLite بوضع `WAL` + قفل خيوط (`RLock`) ومحركات مستقلة؛ بمجرد ظهور أول عميل في الجدول تقدر تبدأ مراسلته فوراً (يدوي أو أوتوماتيك) بينما السحب مستمر في الخلفية.
3. **إصلاح ربط الحسابات والتحقق الفعلي:**
   - التحقق الفعلي من كوكي الدخول (`li_at`) في LinkedIn وقائمة المحادثات في WhatsApp Web، واختبار حقيقي لـ Gmail SMTP.
   - أقفال مستقلة لكل جلسة متصفح لمنع تعارض الملفات.
4. **إرسال يدوي متكامل (Manual Mode — آمن 100%):**
   - لوحة جانبية داخل جدول العملاء للإرسال اليدوي بضغطة واحدة (واتساب / Gmail / SMTP فردي / فتح LinkedIn مع نسخ الرسالة تلقائياً).
   - **طابور الإرسال اليدوي المتتابع (Manual Queue)** للتعامل السريع مع عشرات العملاء يدوياً بدون أي خطر حظر.
5. **درع الحماية من الحظر (Anti-Ban Shield):**
   - 3 مستويات أمان جاهزة (*Warm-up لحساب جديد / متوازن / نشط*)، حدود يومية صارمة متتبعة في قاعدة البيانات، استراحات تلقائية بين الدفعات، محاكاة كتابة بشرية، ودعم **Spintax** لتنويع صياغة كل رسالة تلقائياً، وقائمة **عدم الإزعاج (DNC)**.

## التشغيل والاختبار محلياً
```bash
pip install -r requirements.txt
python test_suite.py
python smart_crm_pro.py
```

## البناء التلقائي لملف EXE عبر GitHub Actions
عند رفع الملفات على فرع `main`، يقوم ملف `.github/workflows/build-windows.yml` بتشغيل الاختبارات التلقائية أولاً ثم بناء نسخة ويندوز جاهزة للتشغيل في تبويب **Actions > Artifacts**.
