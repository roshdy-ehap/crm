# Smart Sales CRM Pro (Full Scraping + Outreach Suite)

تطبيق سطح مكتب متكامل مبني بـ **Python + CustomTkinter + SQLite + Playwright** لسحب العملاء وإدارتهم عبر مراحل المبيعات وإطلاق حملات متعددة القنوات.

## المميزات الرئيسية
1. **محرك سحب العملاء (Scraping Engine):**
   - السحب من **LinkedIn Companies** و **Google Maps** و **محركات البحث (Web)**.
   - تحديد الكلمات المفتاحية، اللوكيشن، الكمية المطلوبة، ونوع بيانات التواصل (واتساب / إيميل / الاثنين معاً).
   - فلاتر مواصفات العميل المستهدف (حجم الشركة، التخصص، أقل تقييم، وجود موقع إلكتروني، وفحص موقع الشركة لاستخراج الإيميل والواتساب).
   - الحفظ التلقائي المباشر في قاعدة بيانات **SQLite** مع منع التكرار.
2. **إدارة العملاء ومراحل المبيعات (CRM Pipeline):**
   - 6 مراحل مبيعات (*جديد ← تم التواصل ← مهتم ← معاينة ← تم البيع ← ملغي*) مع لوحة تحكم وحساب نسبة التحويل.
   - استيراد وتصدير ملفات **Excel (.xlsx)** بأزرار واتساب وإيميل جاهزة.
3. **قوالب الرسائل والحملات متعددة القنوات:**
   - ربط جلسات **LinkedIn** و **WhatsApp Web** و **Gmail SMTP**.
   - إرسال رسائل مخصصة لعملاء محددين أو لمرحلة كاملة مع وضع التجربة (`DRY RUN`) وتأخير عشوائي وإيقاف فوري.

## التشغيل محلياً
```bash
pip install -r requirements.txt
python smart_crm_pro.py
```
> يستخدم التطبيق متصفح **Google Chrome** أو **Microsoft Edge** المثبت على جهازك تلقائياً، وفي حال عدم توفرهما نفّذ `playwright install chromium`.

## البناء التلقائي لملف EXE عبر GitHub Actions
عند رفع الملفات إلى فرع `main`، يقوم ملف `.github/workflows/build-windows.yml` ببناء نسخة ويندوز مضغوطة جاهزة للتشغيل تلقائياً في تبويب **Actions > Artifacts**.
